  <div class="roadmap-list">
    <section class="roadmap-step"><span class="step-number">01</span><div><p class="eyebrow">PROGRAMMING FOUNDATION</p><h2>Learn Python by writing code.</h2><p>Start with variables, strings, numbers, conditions, loops, lists, dictionaries, functions, files, errors, modules, and basic object-oriented programming. Learn to use a notebook and then move one small program into a `.py` file. Type along with a lesson instead of only watching it.</p><ul><li><a href="https://www.youtube.com/playlist?list=PLZPZq0r_RZOOkUQbat8LyQii36cJf2SWT" target="_blank" rel="noopener noreferrer">Bro Code’s Python tutorial playlist</a> — a long beginner series with practice projects.</li><li><a href="https://www.youtube.com/watch?v=XKHEtdqhLK8" target="_blank" rel="noopener noreferrer">Bro Code’s Python full course</a> — use this as a single-video alternative to the playlist.</li><li><a href="https://docs.python.org/3/tutorial/" target="_blank" rel="noopener noreferrer">Python’s official tutorial</a> — return here when you want a written reference.</li></ul><p class="milestone"><strong>Build:</strong> a calculator, quiz, or small program that reads a file and summarizes it.</p></div></section>

    <section class="roadmap-step"><span class="step-number">02</span><div><p class="eyebrow">QUERY AND VERSION YOUR WORK</p><h2>Learn SQL, Git, and GitHub.</h2><p>SQL helps you get the data; Git helps you keep track of your work. Learn to select and filter rows, sort, aggregate, join tables, use subqueries, and then practice CTEs and window functions. Save projects with clear names and commit messages in GitHub.</p><ul><li><a href="https://www.youtube.com/watch?v=5OdVJbNCSso" target="_blank" rel="noopener noreferrer">Bro Code’s SQL full course</a> — covers the basics through joins, grouping, subqueries, and more.</li><li><a href="https://github.com/skills/introduction-to-github" target="_blank" rel="noopener noreferrer">GitHub Skills: Introduction to GitHub</a> — a guided way to learn repository, commit, and pull request basics.</li></ul><p class="milestone"><strong>Build:</strong> answer five questions from a sample database with SQL and save the queries in GitHub.</p></div></section>

    <section class="roadmap-step"><span class="step-number">03</span><div><p class="eyebrow">MATH AND STATISTICS</p><h2>Learn the math that explains the data.</h2><p>Start with ratios, averages, percentiles, spread, probability, distributions, sampling, confidence intervals, and hypothesis testing. Then learn vectors, matrices, and derivatives as they become useful for machine learning. You do not need advanced math before writing your first model.</p><ul><li><a href="https://www.krishnaik.in/ai-tutorials/courses" target="_blank" rel="noopener noreferrer">Krish Naik’s course library</a> — open the Statistics course for a video-led route.</li><li><a href="https://statquest.org/video_index.html" target="_blank" rel="noopener noreferrer">StatQuest video library</a> — clear visual explanations of statistics, machine learning, neural networks, and AI.</li><li><a href="https://www.youtube.com/watch?v=aircAruvnKk" target="_blank" rel="noopener noreferrer">3Blue1Brown: neural networks</a> — a visual introduction to the ideas behind a neural network.</li></ul><p class="milestone"><strong>Build:</strong> explain the mean, median, spread, and one statistical test using a small dataset and a chart.</p></div></section>

    <section class="roadmap-step"><span class="step-number">04</span><div><p class="eyebrow">DATA ANALYSIS</p><h2>Clean, explore, and explain real data.</h2><p>Learn NumPy arrays, pandas tables, missing and duplicate values, type conversion, grouping, joining, dates, and basic visualizations. Practice exploratory data analysis: ask a question, inspect the data, make a chart, and explain what the chart does and does not show.</p><ul><li><a href="https://numpy.org/doc/stable/user/absolute_beginners.html" target="_blank" rel="noopener noreferrer">NumPy absolute-beginners guide</a>.</li><li><a href="https://pandas.pydata.org/docs/getting_started/" target="_blank" rel="noopener noreferrer">pandas getting-started tutorials</a>.</li><li>Use Krish Naik’s <a href="https://www.youtube.com/@krishnaik06/playlists" target="_blank" rel="noopener noreferrer">video playlists</a> for walkthroughs on Python, EDA, and data science projects.</li></ul><p class="milestone"><strong>Build:</strong> one clean notebook that documents a dataset, answers a question, and ends with a short plain-language summary.</p></div></section>

    <section class="roadmap-step"><span class="step-number">05</span><div><p class="eyebrow">CORE DATA SCIENCE</p><h2>Turn an analysis into a defensible conclusion.</h2><p>Practice choosing useful metrics, checking assumptions, separating correlation from causation, and communicating uncertainty. Learn how experiments and A/B tests work. If your goal includes analyst roles, add spreadsheets and one dashboard tool; if your goal is ML, keep building Python and statistics.</p><ul><li>Ask: what decision will this analysis help someone make?</li><li>State where the data came from, what is missing, and what cannot be concluded.</li><li>Make charts readable, label units, and avoid showing a metric without context.</li></ul><p class="milestone"><strong>Build:</strong> a short data report with a question, a few charts, findings, caveats, and a recommendation.</p></div></section>

    <section class="roadmap-step"><span class="step-number">06</span><div><p class="eyebrow">CLASSICAL MACHINE LEARNING</p><h2>Train models and evaluate them correctly.</h2><p>Study regression and classification, then decision trees, random forests, boosting, clustering, and dimensionality reduction. Learn train/validation/test splits, cross-validation, preprocessing pipelines, class imbalance, data leakage, baseline models, and why the metric must match the real problem.</p><ul><li><a href="https://www.krishnaik.in/ai-tutorials/machine-learning" target="_blank" rel="noopener noreferrer">Krish Naik’s beginner Machine Learning course</a> — structured lessons from the first ML concepts through a full workflow.</li><li><a href="https://developers.google.com/machine-learning/crash-course" target="_blank" rel="noopener noreferrer">Google’s Machine Learning Crash Course</a> — concepts, visualizations, videos, and exercises.</li><li><a href="https://scikit-learn.org/stable/getting_started.html" target="_blank" rel="noopener noreferrer">scikit-learn getting started</a> — the practical Python workflow for many traditional ML models.</li></ul><p class="milestone"><strong>Build:</strong> one regression project and one classification project. Compare a simple baseline with a stronger model and explain the evaluation.</p></div></section>

    <section class="roadmap-step"><span class="step-number">07</span><div><p class="eyebrow">DEEP LEARNING</p><h2>Learn neural networks after ML basics.</h2><p>Understand tensors, layers, activation functions, loss, gradient descent, backpropagation, regularization, and training loops. Choose one framework first—PyTorch or TensorFlow/Keras—then build a small image or text model.</p><ul><li><a href="https://www.krishnaik.in/ai-tutorials/courses" target="_blank" rel="noopener noreferrer">Krish Naik’s Deep Learning course</a> — find the course in his structured course library.</li><li><a href="https://pytorch.org/tutorials/beginner/basics/intro.html" target="_blank" rel="noopener noreferrer">Official PyTorch beginner tutorials</a>.</li><li><a href="https://www.youtube.com/watch?v=aircAruvnKk" target="_blank" rel="noopener noreferrer">3Blue1Brown’s neural-network series</a> for visual intuition.</li></ul><p class="milestone"><strong>Build:</strong> train a small model, plot training and validation results, and describe where it makes mistakes.</p></div></section>

    <section class="roadmap-step"><span class="step-number">08</span><div><p class="eyebrow">SPECIALIZE IN AI</p><h2>Pick one area and go deeper.</h2><p>After the foundations, choose a problem area rather than trying to learn every branch at once. Keep the fundamentals in view: data quality, evaluation, reproducibility, and responsible use still matter in advanced AI.</p><div class="track-grid"><div class="track-card"><strong>NLP and LLMs</strong><span>Text, transformers, retrieval, fine-tuning, evaluation, and model cards.</span><a href="https://huggingface.co/learn/llm-course/en/chapter1/1" target="_blank" rel="noopener noreferrer">Hugging Face LLM Course ↗</a></div><div class="track-card"><strong>Computer vision</strong><span>Image data, convolutional networks, transfer learning, and error analysis.</span><a href="https://pytorch.org/tutorials/beginner/basics/intro.html" target="_blank" rel="noopener noreferrer">Start with PyTorch ↗</a></div><div class="track-card"><strong>Applied data science</strong><span>Forecasting, recommendations, experiments, and decision support.</span><a href="https://www.youtube.com/@krishnaik06/playlists" target="_blank" rel="noopener noreferrer">Explore Krish Naik’s playlists ↗</a></div></div><p class="milestone"><strong>Build:</strong> one specialization project using data you can explain and an evaluation that matches its use.</p></div></section>

    <section class="roadmap-step"><span class="step-number">09</span><div><p class="eyebrow">MAKE IT REPRODUCIBLE</p><h2>Learn the tools used to deliver models.</h2><p>Professional ML is more than training a notebook. Organize code, record dependencies, separate training from prediction, create an API or demo, track experiments, and document how someone can reproduce your result. Add cloud tools when a project needs them.</p><ul><li><a href="https://fastapi.tiangolo.com/tutorial/" target="_blank" rel="noopener noreferrer">FastAPI tutorial</a> for serving a small Python API.</li><li><a href="https://docs.docker.com/get-started/" target="_blank" rel="noopener noreferrer">Docker getting started</a> for packaging an application consistently.</li><li><a href="https://www.mlflow.org/docs/latest/ml/getting-started/quickstart/" target="_blank" rel="noopener noreferrer">MLflow Tracking quickstart</a> for recording model parameters, metrics, and artifacts.</li><li>Publish code on GitHub and a model card or demo on <a href="{{ site.huggingface_url }}" target="_blank" rel="noopener noreferrer">Hugging Face</a>. Keep large model files there, not in the website repository.</li></ul><p class="milestone"><strong>Build:</strong> a project someone else can run from your README and, where it makes sense, try in a hosted demo.</p></div></section>
  </div>

  <section class="professional-checklist">
    <p class="eyebrow">WHAT MAKES A PROJECT LOOK PROFESSIONAL</p>
    <h2>Show the decisions, not just the score.</h2>
    <div class="checklist-grid"><div><span>01</span><p>Problem and intended user</p></div><div><span>02</span><p>Dataset source, license, and limits</p></div><div><span>03</span><p>Baseline, method, and metric</p></div><div><span>04</span><p>Results, mistakes, and caveats</p></div><div><span>05</span><p>Reproducible code and clear README</p></div><div><span>06</span><p>GitHub, model, and demo links</p></div></div>
  </section>

  <section class="role-paths">
    <p class="eyebrow">AFTER THE SHARED FOUNDATIONS</p>
    <h2>Choose a professional direction.</h2>
    <div class="track-grid role-grid"><div class="track-card"><strong>Data analyst</strong><span>SQL, spreadsheets, dashboards, data quality, business metrics, and clear reporting.</span></div><div class="track-card"><strong>Data scientist</strong><span>Statistics, experimentation, Python analysis, feature work, machine learning, and explaining uncertainty.</span></div><div class="track-card"><strong>ML engineer</strong><span>Software design, tests, data pipelines, APIs, model serving, experiment tracking, deployment, and monitoring.</span></div><div class="track-card"><strong>AI / LLM engineer</strong><span>Deep learning, transformers, retrieval, prompt and model evaluation, privacy, safety, and reliable product integration.</span></div></div>
    <p class="role-note">You do not need to study every direction. Finish the shared foundations, choose one that interests you, and build projects that show those skills.</p>
  </section>
