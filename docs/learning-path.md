    <h1>A beginner’s path into machine learning.</h1>
    <p class="article-deck">You do not need to learn every equation before you begin. Learn enough to try a small idea, then build your understanding as you go.</p>
  </header>
  <div class="roadmap-note"><span class="roadmap-note-mark">✳</span><p><strong>Use this as a sequence, not a deadline.</strong> Spend more time where you need it. The goal is to understand what your model is doing and explain what you learned.</p></div>
  <div class="roadmap-list">
    <section class="roadmap-step"><span class="step-number">01</span><div><p class="eyebrow">GET COMFORTABLE WITH CODE</p><h2>Learn Python and work with data.</h2><p>Start with variables, lists, loops, functions, and reading files. Then learn enough NumPy and pandas to inspect a table, handle missing values, and make a simple chart. You can practice in Google Colab in your browser.</p><ul><li><a href="https://developers.google.com/machine-learning/crash-course/prereqs-and-prework">Google’s ML Crash Course prework</a> links to the Python, NumPy, and pandas basics it expects.</li><li>Write small programs and explain each line in your own words.</li></ul></div></section>
    <section class="roadmap-step"><span class="step-number">02</span><div><p class="eyebrow">BUILD THE INTUITION</p><h2>Learn the math as it becomes useful.</h2><p>Focus first on averages, distributions, probability, graphs, and the idea of a vector. Later, add derivatives and matrix operations when you study neural networks. Keep connecting each formula to a picture or a small example.</p><ul><li><a href="https://www.youtube.com/watch?v=aircAruvnKk" target="_blank" rel="noopener noreferrer">3Blue1Brown: But what is a neural network?</a> is a visual introduction to the ideas behind neural networks.</li><li><a href="https://statquest.org/video_index.html" target="_blank" rel="noopener noreferrer">StatQuest video library</a> has organized videos on statistics, machine learning, neural networks, and deep learning.</li></ul></div></section>
    <section class="roadmap-step"><span class="step-number">03</span><div><p class="eyebrow">LEARN THE CORE IDEAS</p><h2>Train your first useful models.</h2><p>Study regression and classification, then learn how a model makes predictions, measures error, and improves. Use a simple baseline first. Practice with a train/test split and learn why a good test set must stay separate from training.</p><ul><li><a href="https://developers.google.com/machine-learning/crash-course">Google’s Machine Learning Crash Course</a> teaches these topics with videos, visualizations, and practical exercises. If you are new, follow its modules in order.</li><li>Keep a small glossary: feature, label, loss, training, inference, overfitting, precision, and recall.</li></ul></div></section>
    <section class="roadmap-step"><span class="step-number">04</span><div><p class="eyebrow">MAKE SOMETHING SMALL</p><h2>Finish one end-to-end project.</h2><p>Choose a dataset you can explain. Ask one clear question, inspect the data, make a baseline, evaluate it, and write down what did not work. A complete, honest project teaches more than a folder full of unfinished notebooks.</p><ul><li>Use <a href="https://scikit-learn.org/stable/getting_started.html" target="_blank" rel="noopener noreferrer">scikit-learn’s getting-started guide</a> for a first traditional ML workflow.</li><li>Show your data source, metric, limitations, and next improvement in the project write-up.</li></ul></div></section>
    <section class="roadmap-step"><span class="step-number">05</span><div><p class="eyebrow">GO DEEPER</p><h2>Explore neural networks and PyTorch.</h2><p>Once you can train and evaluate a basic model, explore neural networks. Learn tensors, layers, a loss function, gradient descent, and a training loop. Pick one small task, such as classifying images or text.</p><ul><li>Revisit the <a href="https://www.youtube.com/watch?v=aircAruvnKk" target="_blank" rel="noopener noreferrer">3Blue1Brown neural-network videos</a> for visual intuition.</li><li>Use the <a href="https://pytorch.org/tutorials/beginner/basics/intro.html" target="_blank" rel="noopener noreferrer">official PyTorch beginner tutorials</a> when you are ready to code.</li></ul></div></section>
    <section class="roadmap-step"><span class="step-number">06</span><div><p class="eyebrow">SHARE WHAT YOU LEARN</p><h2>Publish the code, model, and explanation.</h2><p>Put source code in GitHub. If you train a model, publish its model card or demo on Hugging Face. Add a portfolio entry here that explains the problem, method, result, and limitations, then link to those pages. Keep large model files and videos on their hosting platforms.</p><ul><li><a href="https://huggingface.co/CodeWithHammad" target="_blank" rel="noopener noreferrer">Hammad’s Hugging Face profile ↗</a></li><li><a href="https://github.com/hammad-naeem1" target="_blank" rel="noopener noreferrer">Hammad’s GitHub profile ↗</a></li></ul></div></section>
  </div>
