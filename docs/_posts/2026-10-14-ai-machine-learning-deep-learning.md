Artificial intelligence, machine learning, and deep learning are related, but they do not mean exactly the same thing. A useful way to picture them is as nested areas: deep learning is one kind of machine learning, and machine learning is one way to build AI systems.

## Artificial intelligence is the broad goal

Artificial intelligence (AI) is the broad field of making computer systems perform tasks that usually need abilities such as understanding language, recognizing images, planning, or making decisions. An AI system can use learned patterns, hand-written rules, search, or a combination of approaches.

That means AI is not limited to chatbots. A program that plans a route or chooses a move in a game can also be described as AI, even if it does not generate text.

## Machine learning learns from examples

Machine learning (ML) is an approach where a computer uses data to learn patterns for a task instead of relying only on a programmer writing every rule by hand.

For example, to estimate a home’s price, a model might learn from examples containing home sizes, locations, and previous sale prices. Once trained, it can estimate a price for a new home. That estimate is a prediction; it is not automatically correct, fair, or useful. The data and the way we evaluate the model matter.

Common ML tasks include predicting a number, assigning a category, grouping similar items, and recommending something a person may want to see.

## Deep learning uses layered neural networks

Deep learning is a part of machine learning that uses neural networks with many layers. These models can learn useful representations from complex inputs such as images, audio, and text. They often need more data and computing resources than a small traditional model, so they are not the right choice for every problem.

Many modern generative AI systems use deep learning to produce text, images, audio, or code. Still, “AI” and “generative AI” are not synonyms: some AI systems do not generate content, and AI includes approaches beyond deep learning.

## A simple way to keep the terms straight

- **AI:** the wider goal or field.
- **Machine learning:** one way to build systems that learn patterns from data.
- **Deep learning:** a family of ML methods based on multi-layer neural networks.

When you look at a model, ask what input it uses, what task it is meant to perform, what data it learned from, and how its mistakes are measured. Those questions are more useful than calling every new tool “AI.”
