    <p class="eyebrow">GENERAL CS <span>/</span> FOUNDATIONS IN PROGRESS</p>
    <h1>Computer science, one concept at a time.</h1>
    <p class="article-deck">Alongside data science and machine learning, I’m learning the broader ideas behind programming and software. This page is a beginner’s topic map; I’ll add notes and small examples as I study.</p>
  </header>

  <div class="roadmap-note"><span class="roadmap-note-mark">✳</span><p><strong>A learning list, not a claim of mastery.</strong> I’m working through these foundations gradually. Each short note or example can be added here as I learn and practice.</p></div>

  <div class="roadmap-list">
    <section class="roadmap-step"><span class="step-number">01</span><div><p class="eyebrow">PROGRAMMING FUNDAMENTALS</p><h2>Break a problem into small steps.</h2><p>Practice variables, conditions, loops, functions, collections, files, errors, and writing code that is easy to read. Python is a useful place for me to practice these basics.</p><p class="milestone"><strong>Small practice:</strong> write a simple program, explain what each part does, and improve it after trying a few inputs.</p></div></section>

    <section class="roadmap-step"><span class="step-number">02</span><div><p class="eyebrow">DATA STRUCTURES + ALGORITHMS</p><h2>Learn how information is organized.</h2><p>Explore lists and arrays, dictionaries and hash maps, stacks, queues, trees, and graphs. Then practice searching, sorting, and describing how an approach changes as the input gets bigger.</p><p class="milestone"><strong>Small practice:</strong> compare two ways to find an item in a list and write down how they work.</p></div></section>

    <section class="roadmap-step"><span class="step-number">03</span><div><p class="eyebrow">DATABASES + SQL</p><h2>Store information and ask questions about it.</h2><p>Get familiar with tables, rows, columns, keys, basic database design, and SQL queries. Build from filtering and sorting to grouping, joins, and simple ways to keep data consistent.</p><p class="milestone"><strong>Small practice:</strong> use SQL to answer a few questions from a sample database. See the <a href="{{ '/learning-path/' | relative_url }}#video-classroom">Python and SQL learning resources</a>.</p></div></section>

    <section class="roadmap-step"><span class="step-number">04</span><div><p class="eyebrow">HOW COMPUTERS WORK</p><h2>Understand the pieces behind a program.</h2><p>Start with files, processes, memory, and the role of an operating system. Learn basic networking ideas such as addresses, DNS, HTTP, and how a browser and server exchange information.</p><p class="milestone"><strong>Small practice:</strong> follow what happens from typing a website address to seeing a page load.</p></div></section>

    <section class="roadmap-step"><span class="step-number">05</span><div><p class="eyebrow">LOGIC + DISCRETE MATH</p><h2>Practice precise ways to reason.</h2><p>Explore true-or-false logic, sets, functions, number systems, and simple counting. These ideas help make conditions, algorithms, and data representations easier to understand.</p><p class="milestone"><strong>Small practice:</strong> explain a short logical rule with a truth table or a few examples.</p></div></section>

    <section class="roadmap-step"><span class="step-number">06</span><div><p class="eyebrow">TOOLS + SOFTWARE PRACTICE</p><h2>Build, check, and explain small programs.</h2><p>Use Git to track changes, GitHub to share code, and simple tests to check expected behavior. Learn to read error messages, document how to run a project, and keep secrets out of public code.</p><p class="milestone"><strong>Small practice:</strong> publish a tiny project with a clear README and a few checks.</p></div></section>
  </div>
