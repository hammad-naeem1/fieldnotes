# hammad.dev — Computer Science & Software Engineering Portfolio

Welcome to the central repository for **hammad.dev**, a personal website showcasing computer science notes, software engineering projects, machine learning experiments, and technical write-ups.

Live Website: **[https://hammad.dev.is-a.dev](https://hammaddev.is-a.dev)**

---

## 📌 About The Site

**hammad.dev** is a lightweight, markdown-driven static site published using GitHub Pages and served under a custom domain. It acts as an open-notebook portfolio where I document my journey through software development, machine learning, databases, and general computer science fundamentals.

### Key Features
* **Technical Blog:** Articles on Python development, machine learning experiments, and algorithms.
* **Project Portfolio:** Showcase of real-world projects, data science workflows, and code repositories.
* **General CS Notes:** A curated study map covering algorithms, SQL, computer systems, and developer tools.
* **No Trackers or Framework Overhead:** Fast, static delivery designed for clean readability and minimal load times.

---

## 🛠️ Stack & Architecture

* **Publishing Platform:** GitHub Pages
* **Domain & DNS:** Custom sub-domain via `is-a.dev` (`hammad.dev.is-a.dev`)
* **Content Engine:** Jekyll / Markdown (`docs/` directory deployment)
* **Model & Media Hosting:** External integration with Hugging Face for model weights and interactive demos.
